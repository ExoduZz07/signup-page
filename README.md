# Minimalist Sign Up Page with Admin Dashboard (GitHub Pages Ready)

A clean, minimalist sign up page with a **private Admin Dashboard** designed specifically for deployment on **GitHub Pages**.

---

## 🔒 Security & Privacy

1. **Public Sign-Up (`index.html`)**:
   - Visitors **only** see the sign up form and a confirmation screen.
   - **Zero public database access**: Visitors cannot view or inspect registered accounts.

2. **Admin Dashboard (`admin.html`)**:
   - Password / PIN-gated portal (default PIN: `admin123`).
   - Shows all signups with live search/filtering by name or email.
   - **Export to CSV** or **JSON** with one click.
   - Individual user deletion and full database reset.

---

## ⚙️ Configuration (`config.js`)

Open `config.js` to customize:

- **Change Admin PIN**:
  ```js
  ADMIN_PIN: 'your-secure-passcode',
  ```

- **Cloud Database (Supabase)**:
  By default, data is stored in the browser's persistent **IndexedDB**.
  To collect signups from multiple users across the web into one central cloud database:
  1. Create a free account at [Supabase](https://supabase.com).
  2. Create a project and run this SQL in the SQL Editor:
     ```sql
     create table public.signups (
       id bigint generated by default as identity primary key,
       name text not null,
       email text unique not null,
       created_at timestamp with time zone default timezone('utc'::text, now()) not null
     );

     -- Enable Row Level Security (RLS)
     alter table public.signups enable row level security;

     -- Allow anyone to INSERT their signup
     create policy "Public insert only" on public.signups
       for insert with check (true);
     ```
  3. Paste your URL & Anon Key into `config.js` and set `DATABASE_PROVIDER: 'supabase'`.

## 🚀 Launching on GitHub Pages

1. Go to [github.com/new](https://github.com/new) and create a repository (e.g. `minimal-signup`).
2. Upload all files from this folder (`index.html`, `admin.html`, `style.css`, `app.js`, `admin.js`, `db.js`, `config.js`).
3. In repository **Settings** → **Pages**, set branch to `main` and root `/`, then save.
4. Your site will be live at:
   - **Public Page**: `https://<your-username>.github.io/<repo-name>/`
   - **Admin Portal**: `https://<your-username>.github.io/<repo-name>/admin.html`
